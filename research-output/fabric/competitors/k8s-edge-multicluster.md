# Competitors: Kubernetes edge and multi-cluster (FB-11, group 3)

**Date:** 2026-11-12. Versions: [C-FB11-001], mission 01 C-W4-048/049.

> **Explain it like I'm the founder.** There are two families. **"One cluster, far-away nodes"** (KubeEdge, OpenYurt) keeps a single Kubernetes brain in the cloud and lets edge machines limp along when cut off; that clashes with "home is the authority". **"Many clusters, one hub"** (Rancher Fleet, Open Cluster Management, Argo CD's agent mode) lets each site keep its own brain and pull instructions from a hub; that matches OneMind. Fleet was tested in this run's lab.
