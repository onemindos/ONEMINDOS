# Sources: ARCH5 (critic pass-5 gap P5-7, six decision-grade ARCHIVE-GAP sources)

All fetched on 2026-11-11. Claims: [`../claims/ARCH5.csv`](../claims/ARCH5.csv) (C-ARCH5-001…004; each one re-confirms an existing claim and adds no new decision fact). Saved copies are in [`ARCH5/`](ARCH5/), with hashes in [`ARCH5/SHA256SUMS`](ARCH5/SHA256SUMS). That file gives two kinds of hash: `raw-download:` is the hash of the bytes as downloaded (those files are not committed), and the plain filenames are hashes of the saved text copies. No Wayback captures were made, because save requests are blocked in this environment.

> **Explain it like I'm the founder.** Web pages change. Six pages that the foundation decision (01) leans on had no saved copy, so a reader could not check them later. This pass fetched each one again, saved the text, and recorded its fingerprint (sha256). Four are now fully preserved. One (Canonical's trademark policy) already had a saved copy from the licence work, so it only needed linking. One (a Launchpad bug) cannot be reached from this environment, so part of it stays a gap, and there is a step below for you to run.

**Masking.** Each copy was checked for e-mail addresses, token-shaped strings, analytics or account IDs and private IPs before hashing. Nothing in the five saved bodies needed masking. Two things were removed instead of masked:
- **Raspberry Pi news post:** reader comments, because they carry commenters' names. Site navigation was also removed. Only the article body is kept.
- **GitHub PR:** user handles and API URL templates. The PR was cut down to its fact fields with `jq`.

  Mask any e-mail address in the file, then save it as `evidence/sources/ARCH5/launchpad-2170238-bug.json.txt` and add its hash to `ARCH5/SHA256SUMS`. **Pass:** the `description` field mentions "of: Improve compatibility with old Pi 5 firmware" and the EEPROM dates quoted in C-DEC-006. **Fail:** the text differs. Then re-read DC-19's tie-break row in 01.
- **F-2 (optional, C-W2-050).** If you want a fresh copy of the Canonical policy, save https://canonical.com/legal/intellectual-property-policy as text. Diff it against `LIC/05-canonical-iprights-policy.txt`; section 3 should be unchanged.
- **F-3 (C-CIT4-008 caveat).** Open https://www.raspberrypi.com/products/raspberry-pi-5/ in a normal browser and save the page as text. **Pass:** you record whether it still says the 16GB model "is available now for $305" or now shows $385.
- Optional for all six: request Wayback captures from a normal browser. This environment refuses Wayback save requests.

## Method

- Downloads went to an empty scratch folder outside the repo. The HTML was converted to text with a short Python script using the standard-library parser (run with `python3 -I`, from a separate folder). Scripts, styles and markup were dropped. No downloaded code was run.
- A WebFetch read was **not** used for the two DNS-blocked hosts. Its output is a model summary, not a byte copy, so it cannot be hashed as the source. Using it would also have meant working around the block.
