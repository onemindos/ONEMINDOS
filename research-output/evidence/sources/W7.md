## Archive method

The Wayback Machine "save" requests were blocked in this environment (an automated permission control refused the outbound upload). This file uses the brief's other allowed method (§2 rule 1): a saved copy of each load-bearing web page in `evidence/sources/W7-archive/`, with its SHA-256 listed in `W7-archive/manifest.txt`.

- Two pages (Boston Dynamics CORE I/O and Clearpath) contained vendor example addresses from an RFC1918 private range. In the committed copies those addresses are replaced with `[RFC1918-redacted]`. The manifest lists both the original and the redacted hashes.
- Each page was first saved as HTML and hashed (`manifest.txt`). The committed copies are **plain text with scripts and styles stripped** (`.txt`), because the raw HTML contained public analytics/search keys that the repo's gitleaks check flags, and one corporate press e-mail address (replaced with `[email-redacted]`). `text-hashes.txt` lists the hash of each committed text file next to the hash of the HTML it came from.
- Git-hosted sources are cited as permalinks pinned to a commit SHA or tag, so they need no separate archive.
- Shallow clones used for code reading are in `../.lab/src/`, outside the repo.
