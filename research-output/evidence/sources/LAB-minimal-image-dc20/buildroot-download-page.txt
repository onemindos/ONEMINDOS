 Git repository 
 The buildroot repository can be browsed online at
 https://gitlab.com/buildroot.org/buildroot/ . 
 To grab a copy of the repository use 
 git clone https://gitlab.com/buildroot.org/buildroot.git 
 If you are not already familiar with using Git, we recommend
 you visit the Git
 website . 
 Once you've checked out a copy of the source tree, you can
 update your source tree at any time so it is in sync with the
 latest and greatest by entering your buildroot directory and
 running the command: 
 git pull 
 Because you've only been granted anonymous access to the
 tree, you won't be able to push your changes to the
 repo. Changes can instead be submitted for inclusion by
 posting them to the buildroot mailing list.
