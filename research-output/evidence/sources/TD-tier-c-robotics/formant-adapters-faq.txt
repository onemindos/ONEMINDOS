# Does the agent restart adapters?

# Q: In testing, some of my Python adapter scripts exit with an error message, and the adapter sometimes does not seem to restart. Will Formant relaunch adapters automatically on any type of failure? Are there a maximum number of restart attempts?

***

Yes, if you use adapters, the Formant agent will manage automatically restarting the specified command to run. No max number of restarts.

However, the adapter will not constantly try to re-run adapters back to back. Adapters are restarted with an increasing delay to avoid overloading the Formant agent, with a maximum interval of 60 seconds between restarts.
