# Sources · REPORT (founder PDF, F-10)

The founder report (`report/`, `ONEMIND-OS-FOUNDATION-REPORT.pdf`) introduces **no new sources and no new claims**. Every bracketed claim ID in it resolves to a row in another tag's ledger in `evidence/claims/`, and its source is listed in that tag's `evidence/sources/<TAG>.md`. `report/chapters/17-appendix-claims.md` (generated at build time) lists the source URL, type, status and access date of every ID the report cites. `evidence/claims/REPORT.csv` is therefore header-only.
