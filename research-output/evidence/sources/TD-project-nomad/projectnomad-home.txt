The short version
What is Project NOMAD™?
An offline-first knowledge and education server
: a free, open source offline server you install on any computer. Download the content you want, and it keeps working without internet, forever. The optional AI runs entirely on your own hardware, so it stays private, with no cloud and nothing sent anywhere. Prefer just the knowledge library? You can leave the AI out. Similar products cost hundreds of dollars. Project NOMAD is free.

Hardware
NOMAD runs on serious hardware so you get serious AI. While other offline products are stuck on Raspberry Pis, NOMAD supports GPU-accelerated inference on models with real intelligence. Community builds range from refurbished desktops to GPU-powered rigs scoring 60 to over 3,000 on the NOMAD Benchmark.
Looking for something lightweight for a Raspberry Pi? Check out projects like
Internet in a Box
. Project NOMAD is for when you want the full experience.

Install in
60 Seconds
Two commands on any Ubuntu or Debian machine, no Linux experience needed. The installer sets up Docker, dependencies, and everything else for you.
$
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/main/install/install_nomad.sh -o install_nomad.sh
$
sudo bash install_nomad.sh
Ubuntu 26.04 LTS recommended (22.04+ or Debian 12+ supported). Docker is installed automatically if needed.
