Project NOMAD runs on any x86 Linux computer. Here are our recommended builds at three price points, based on real performance data from the community leaderboard.
How to read a NOMAD Score.
It's an index, not a percentage out of 100. Our reference build, a Ryzen 9 PRO 8945HS with Radeon 780M graphics, scores exactly 1,000. A machine that scores 2,000 is twice as fast across the benchmark as a whole, and there is no ceiling.

GPU note
Project NOMAD auto-detects NVIDIA and AMD GPUs and configures Ollama for GPU acceleration. On NVIDIA, install the NVIDIA Container Toolkit on your host and Project NOMAD handles the rest. GPU prices are inflated, a used RTX 3060 runs $200–$300, a used RTX 3090 runs $700–$1,000, and new RTX 50-series cards start around $550.

Operating System
Project NOMAD requires Ubuntu or Debian-based Linux. We recommend Ubuntu 26.04 LTS, which is what we test on. The install script handles everything else, Docker, the database, the web interface, all of it.

Power & Connectivity
Project NOMAD is designed to work offline, but you need power. Some things to consider:
A mini PC draws 15–65W depending on load, easily powered by solar + battery
Connect a WiFi router or access point to your Project NOMAD box so devices can connect to it
An uninterruptible power supply (UPS) protects against sudden shutdowns
For a truly off-grid setup: solar panel + battery + mini PC + WiFi access point = complete offline knowledge station.
