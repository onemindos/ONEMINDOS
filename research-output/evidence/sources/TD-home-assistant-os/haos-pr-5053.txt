Each build job writes a per-board `SHA256SUMS` fragment for its `haos_*` images. Once all boards are built, a separate `sign` job merges them into one `SHA256SUMS`, signs it with `cosign sign-blob` via GitHub OIDC and publishes `SHA256SUMS` and `SHA256SUMS.sigstore.json`: as release assets on releases, next to the artifacts on R2 for published dev builds. Installers such as the upcoming Home Assistant installer can verify an image by checking the bundle against this workflow's identity on a release tag and then the image's digest against `SHA256SUMS`. Trust is anchored in Sigstore's public root plus the workflow identity in the certificate, the same approach Supervisor and the version repo already use. Version bumps and the artifacts index wait for signing, so a version is never published without its signature.
