## How these sources were read

- **Code and in-repo docs** were read from shallow clones (`--depth 1 --filter=blob:none`) in `../.lab/src/` (outside the repo), pinned to the commit SHAs below. GitHub permalinks pinned to those SHAs are the archive: a commit SHA cannot change.
- **GitHub API metadata** (commit counts, authors, releases, issues) came from authenticated `gh api` calls on 2026-11-10. Results can change as new commits land; the query URL and date are recorded.
- **Web pages** were read through a fetch tool that returns a model summary of the page, so wording from web pages is paraphrase-grade unless quoted from a repo file. Re-open before quoting externally.
- **Archiving:** saving new Wayback snapshots was refused by this environment's permission policy (it counts as a public upload). For every load-bearing web page this file records (a) the closest *existing* Wayback snapshot found with the read-only availability API, and (b) the SHA-256 of the page bytes as fetched on 2026-11-10. Pages with no existing snapshot are flagged **ARCHIVE-GAP**; Zeus or a later run should save them (`https://web.archive.org/save/<url>`).
