> ❗ **Important:** Please note that only admins can request a data export.

You can request an export of your data at any time by reaching out to us at [**<vendor-support-email>**](mailto:<vendor-support-email>).&nbsp;  
  
Data export is currently sent in four CSV files that include the following information fields:

## **Members**

- User ID

- First and last name

- Email

- Join date

- Active status (if the member has signed in the last 30 days)

- Member tags

- Headline

- Profile URL

- Number of comments, posts, and likes received

- Space access

- Avatar URL

- Last active information

- Total Gamification Points

- Gamification level, name and progress

- Gamification Points To Next Level

- Gamification Level Progress

- Bio

- Website

- Twitter URL

- Location

- LinkedIn, Instagram, Facebook URL

- Profession

- Birthday

- Company

- Activity score and presence

## **Spaces**

- Space ID

- Space name

- Space slug

- If space access is set to private

- If space is hidden from non-members

- Number of posts in the space

## **Posts**

- Post ID

- Space ID

- Created at

- Post title (name)

- Post slug

- Number of comments and likes

- Post body

- Member name (post author), ID, and profile URL

- HTML body

## **Comments**

- Comment ID

- Post ID

- Created at

- Space ID

- Parent comment (if threaded)

- Comment body

- Member name (comment author), ID, and profile URL

> ℹ️ **Note:** &nbsp;Posts and comments CSV won’t include any uploaded media.

## Events

- Event ID

- Space ID

- Created at

- Event name

- Event body (description)

- Slug

- Start and end time

- Duration

- Location

- Number of RSVPs

- Member name, ID, and profile URL
