# Sources: W9 (AI capability layer)

Used in `research-output/10-ai-capability-layer.md`. Claim rows are in `evidence/claims/W9.csv`. Accessed 2026-11-10 (UTC; local date of the run 2026-11-11).

**Saved copies.** Load-bearing web pages were fetched with curl on 2026-11-10, stripped to plain text, and saved in `evidence/sources/W9/` with hashes in `W9/SHA256SUMS`. Before hashing, email addresses were replaced with `[email-redacted]`, the example private IP addresses on the MCP security page were replaced with `<rfc1918-example-masked>`, and the names of individual people in the Anthropic MHS post were removed. Very large legal texts (GDPR, AI Act, Digital Omnibus, WebAuthn) are saved as **excerpts**; the first line of each excerpt records the sha256 of the full raw HTML that was downloaded. Wayback save requests are denied in this environment; existing captures are listed where they exist.

**Code** was read from shallow clones (`--depth 1 --filter=blob:none`) in `<lab-dir>/src/` (outside the repo). Code citations are GitHub permalinks pinned to commit SHAs, which serve as their own archive. Nothing was built or run.
