# Base layer, Debian 13 leg (brief 30 B2). Versions come from the pinned snapshot

# ("<package> <version> <arch> <installed size in KiB>" per line, the size for the size budget).
systemd systemd-sysv systemd-resolved udev dbus login passwd
# Clock: recommends are off (configure-apt), so the NTP client and the zone database are listed by name. node-check.sh reads
# NTPSynchronized; snapper and the update gate need a correct clock (Step 2, PR 1).
systemd-timesyncd tzdata
# Compressed RAM swap (zram) so one big app cannot push the control plane into the OOM killer
systemd-zram-generator
kmod iproute2 iptables nftables procps util-linux mount e2fsprogs dosfstools
# sfdisk (data_extend.py) is in its own package on Debian 13, not in util-linux
fdisk
# backups: online copies of the gateway and k3s SQLite databases (internal/backup, IMG-BACKUP-01)
sqlite3
ca-certificates curl socat zstd squashfs-tools
apparmor
# OneMind layer: onemind.local over mDNS; openssl for the per-box CA at first boot (docs/leap/core/IMAGES.md)
avahi-daemon avahi-utils openssl
# File sharing (D-017): Samba with the vfs_fruit module for Time Machine, and the NSS module that lets Samba name its
# per-person accounts from /data (the root is read-only). The Debian smbd, nmbd and winbind units are masked below.
samba samba-vfs-modules libnss-extrausers
# Desktop apps from Flathub (#1097): Flatpak itself. One system installation on /data (installations.d/onemind.conf), so the
# read-only root is untouched and the apps survive a reboot and an A/B update. No remote is added until an owner searches.
flatpak
# NAS client tools (#871): mount an SMB or NFS share from a NAS as a Files location (#718). Clients only: no
# nfs-kernel-server or ksmbd-tools, and the rpcbind and nfs-client units nfs-common enables are disabled below
# (os/rootfs/Containerfile); rpc-statd still starts on demand for an NFSv3 lock. The kernel's cifs and nfs modules
# come with linux-image-*. Battery step: test/qemu/CRITERIA-NAS.md (TN0-TN2).
cifs-utils nfs-common
initramfs-tools
# Boot splash (brand/generated/os/plymouth): graphical console only, the serial console is untouched
plymouth plymouth-label fontconfig fonts-dejavu-core
# Console keyboard and charmap for the tty2 login (Step 3): console-setup gives setupcon and ckbcomp (xkb-data layouts),
# kbd gives loadkeys and dumpkeys. Its own units are masked (they cache under the read-only /etc);
# onemind-console-keyboard.service loads the layout kept on /data. Proof: first-boot checks F30 and F31.
console-setup keyboard-configuration
grub-common
# RAUC 1.15.2 runtime libraries (RAUC itself is built from source; Debian's rauc is never installed)
libglib2.0-0t64 libssl3t64 libcurl4t64 libjson-glib-1.0-0 libfdisk1 libnl-genl-3-200
# Encrypted /data (data_encrypt.py): cryptsetup, systemd-cryptsetup (systemd-cryptsetup + systemd-cryptenroll) and the
# TPM2 libraries systemd loads at run time for tpm2-device=auto. Debian 13 package names, checked with apt-cache.
# btrfs-progs: /data is btrfs with subvolumes @ and @storage (#152).
cryptsetup-bin systemd-cryptsetup btrfs-progs libtss2-esys-3.0.2-0t64 libtss2-rc0t64 libtss2-mu-4.0.1-0t64 libtss2-tcti-device0t64
# Snapshots of the owner's files and the monthly scrub (plan PR 6, #152). snapper: Debian 13 has 0.10.x; btrfsmaintenance
# 0.5.x. Configs are baked into /etc (read-only root); units are enabled or masked in os/rootfs/Containerfile.
snapper btrfsmaintenance
# UPS support (IMG-06, #244): NUT's client (upsmon, upsc) and server (upsd, upsdrvctl, nut-scanner, the USB drivers
# and the udev rule that gives the nut group the UPS). The Debian nut-* units are masked; onemind-ups*.service run it.
nut-client nut-server
# Disk and admin tools (Step 2 PRs 4 and 7). smartmontools is what internal/storage/smart.go calls (smartctl); its
# smartd daemon (smartmontools.service, alias smartd.service) runs with /etc/smartd.conf and feeds Notifications (P-10). gdisk gives sgdisk, btrfs-progs the btrfs tool
# for the coming btrfs /data. The rest is what an owner expects on an SSH or rescue shell. Proof: first-boot check F13.
smartmontools gdisk btrfs-progs
bash-completion less nano rsync htop jq iputils-ping pciutils usbutils dmidecode ethtool
# Owner shell (Step 2): SSH (key-only, starts once the owner adds a key), sudo with the console password, and the
# PAM module that gives every login (SSH, tty2, the kiosk user) a logind session. Recommends are off, so listed here.
openssh-server sudo libpam-systemd
# Man pages: `man onemind` (the pages are generated from the CLI at image build; proof: first-boot check F14).
man-db
# Box care for a 24/7 machine (Step 2b): fwupd (firmware updates through LVFS, owner-approved only: the refresh timer
# is masked in os/rootfs/Containerfile), lm-sensors (the sensors command), rasdaemon (hardware error log, its database
# on /data), udisks2 (USB drives: detect only, never auto-mounted, os/rootfs/layers/base/usr/lib/udev). fstrim.timer
# comes with util-linux; polkitd is not installed, so only root (the host helper) may mount or flash. Proof: first-boot check F24.
fwupd lm-sensors rasdaemon udisks2
# Printing (Step 3): CUPS with driverless (IPP Everywhere) printing. No cups-browsed: it would add queues by itself,
# and adding a printer is an owner action. ipp-usb lets a USB printer speak IPP; avahi (above) announces it. "cups" brings
# the web admin (the CGI programs) and cups-ppdc (the generic PPDs); the rest are named so a dependency change shows.
cups cups-client cups-daemon cups-filters cups-ipp-utils ipp-usb
