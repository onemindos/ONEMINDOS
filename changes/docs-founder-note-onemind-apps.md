Founder note 14 is a web page about OneMind's own apps: the nine registered built-ins, the sixteen apps that are built but not yet registered (Messages included: its descriptor is written and it joins the signed list with #856), and the seventeen planned, each with its issue. It compares built-in, Market and custom apps (D-026), shows how an AI agent reaches any app through the gateway's MCP door (read tools and request-only tools; only a person approves), and recommends what to build next. It adds no decision and lists the three founder decisions still open.

Adds the Codex prompt `docs/leap/dev/CODEX-PROMPT-BUILT-INS.md` for registering the built-and-working apps as built-ins (#1261 to #1264).

Founder note 15 explains how one OneMind app serves every module on every device: one shell per platform (web desktop, phone, headset), module screens sent as data and drawn by two renderers (#641, #642), and hand-built screens only for Approvals, Map, Photos and Files. It recommends owning the experience and borrowing open-source engines underneath, and a 3D split (MapLibre 2D, CesiumJS outdoor 3D, three.js indoor). The own-vs-borrow rules and the 3D split wait on the founder.
