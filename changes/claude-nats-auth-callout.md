NATS can now ask the gateway who may connect (D-029, the hybrid). With the installer switch ONEMIND_FABRIC_NATS_CALLOUT=1 (off by default: D-029 keeps today's static file for now), the hub's NATS sends every client that is not on its pinned list to the gateway: hub services, machines and the gateway's own responder are pinned and never wait for the gateway, so machines keep reconnecting when it is down. The gateway admits only a registered AI agent key whose holder signed the server's one-time nonce, never while the agent kill switch is on, and answers with a short-lived user JWT (10 minutes by default) carrying exactly that agent's allow lists; every answer is an audit line. Removing an agent's key or pressing the kill switch refuses its next connect without a NATS reload, and the JWT's expiry cuts a live connection by then at the latest. No answer means no connection (fail closed). The JWTs are written with the library the gateway already has; the official Go JWT library validates them and nats-server 2.15.3 runs the rendered config in the tests. Not yet: xkey encryption of the callout request (needs PyNaCl), and showing an agent's credential expiry on its page.
