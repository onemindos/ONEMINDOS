The Messages contract for the LoRa messenger on MeshCore (#855, part 1 of 2), written before any module so the hub driver, the gateway, the phone and the dashboard build against the same shapes. New JSON Schemas describe a stored message (transport lora-mc; lora-mt, the 1.1 Meshtastic bridge, is refused), a radio's own report in physical units, the five signed radio jobs onemindd will accept (inbox, status, send, advert, channel set; none can change frequency, bandwidth, spreading factor, coding rate or power), the two message events (ids only, never the text) and the direct-mode import body with its de-duplication key. The subject tree gains the two gateway-only event subjects and reserves lora, radio and message so nothing on the bus can make a radio transmit. The Messages built-in descriptor and its action specs keep a person on every send and advert (agents may only ask; no automation or standing approval). The shared MeshCore frame and guard vectors and the Meshtastic licence guard follow in a second pull request on the same issue.
