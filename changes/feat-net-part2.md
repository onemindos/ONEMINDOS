Networking part 2 (CORE-NET-11, CORE-NET-12, CORE-NET-13): a machine joins the box with a one-time code and an owner approval (`onemind fabric join`, `ticket`, `approve` and `status`), over a Headscale mesh, with a per-node NATS account and TLS (H-06), HTTPS on the box CA at :443 and :8443, app names under `<app>.<box>.local`, and the per-app reverse proxy; `deploy/install.sh` becomes mesh-first (`--join`, `--box-name`, `--lan-addr`) and never takes over a Tailscale client the machine already had, keeping the offline bundle, dry run and backup setup. Security fixes in this PR, each with a test: with HTTPS on, the gateway's plain-HTTP listener binds to loopback only (H-05); the proxy strips every `onemind_*` and `__Host-onemind_*` cookie before a request reaches an app and refuses an app's `Set-Cookie` for those names (H-34); `onemindd` supervises the NATS leaf from a persisted leaf config, reloading it on change and restarting it after repeated failed checks (CS2-06). The 2-VM proof (`test/net/two_vm.py`, criteria in `test/net/CRITERIA-2VM.md`, workflow `net-2vm.yml`) runs strict on pull requests, so a criterion that could not run fails the job. An app pod on another node is now reachable from the hub gateway: the app's allow policy admits the hub's host addresses (flannel address and node IP, as /32) on the app's web port only, nothing wider. Cross-node pod traffic also needed Tailscale kept off flannel's interfaces: Tailscale offered the flannel-wg address as a peer path and looped its own traffic through it, so `tailscaled` now loads a small nftables table (`mesh-guard.nft`) that drops its UDP port on `flannel*` interfaces.
