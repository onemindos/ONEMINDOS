The surface registry (#605). Each gateway tool is now declared once in `core/onemind_core/surfaces/core.py`, with the REST route it reads, its effect (read, write or destructive), its exposure (mcp, rest, cli) and the token scope it needs. The MCP tool list, the per-tool scopes on `/mcp` and the `/mcp` route description are all built from that one list, so there is nothing left to edit by hand in `mcp/tools.py`. `GET /v1/surfaces` (scope `apps:read`) gives every client one list of what the switched-on apps plug into: tools, cards, search providers, share targets, notification topics, map layers, Settings pages and backup units. It is read live, so when an app is switched off its tools leave `tools/list` and every other list straight away, and they come back when it is switched on. Three kinds of declaration are refused, listed under `refused` with the reason, and never served: a tool whose action type the gateway has not registered, a topic naming an event the notify catalogue does not send to it, and a card whose source does not report `observed_at`. Today the Backups last-backup card is refused for that reason. A new CI parity test (`core/tests/test_surfaces.py`) checks every route the gateway serves. Each route must have a tool, or appear in `HUMAN_ONLY` (in `surfaces/parity.py`) with a named reason: oversight, credential, person, bytes, door or write. A third list, `AWAITING_TOOL`, holds reads still waiting for their tool (#632), and it may only shrink: the test holds a frozen snapshot of it and fails when a route is added. Confirming a found radio is human-only (oversight), and `GET /v1/surfaces` itself is a door, not a parked read. A new route on none of these lists fails CI. The test also calls every read tool and its REST route as the same agent and checks that both return the same body. Slice 2: installed Market apps join `GET /v1/surfaces` from their approved installation receipt (never the catalog file), and only while installed and running that receipt. Each served tool is listed as `<app_id>.<tool>` with its declared effect, its REST route and the plugin.invoke scope; a write or destructive tool files a request a person approves. A declared tool the gateway does not serve is refused, and so is a template widget whose source is not one of the app's own read tools with `observed_at` in its output. A Market app also brings its search provider, share target, map layers, notification topics (refused unless the notify catalogue routes them), its Settings page and a whole-app backup unit. Stopping or removing the app takes all of it off every list at once.
