CI-13: the founder's Mac now carries every CI job it can, so GitHub's runners only do the x86, KVM and Docker work. A new gate pool (label onemind-gate, its own switch LOCAL_GATE) takes merge-gate, which only polls the GitHub API and used to hold most hosted slots: up to 4 slots (at most 8), each running one job in a fresh 1-CPU, 1 GB clone that is deleted afterwards. The runner loop sets LOCAL_GATE=on only while gate slots run, so an empty or broken gate pool never stalls merges. Registration tokens reach config.sh in an environment variable, never on a command line. The worker pool grows to up to 3 fresh-clone VMs (3 CPU and 6 GB each on a 12-core, 32 GB Mac) and also takes ci changes and dco, hygiene, the ci-core plan and its 3 SQLite shards (now a job of their own, without service containers), ci-mobile typecheck and jest, e2e-unit, brand, the ui-quality build and the site build. Every moved job keeps its pool's switch, never runs a fork PR or a pull_request_target, workflow_run or issue_comment workflow and falls back to ubuntu-24.04; a policy test keeps x86, KVM, Docker, secret and write jobs off the Mac and keeps merge-gate always reporting. Switch-on steps are in docs/learning/self-hosted-runner.md.
