Phone parity, people and AI: a People screen under More (owner only) lists everyone with their role (Owner, Adult, Teen, Child, Guest), shows each young person's limits read from the hub, and lets an owner add a person or change a role with a two-tap confirm while the hub enforces owner-only and asks for a fresh passkey. Teen and Child see Ask a parent instead of Ask to install, which files a normal install request that lands in the parent's Approvals; the Apps list shows the hub's age rating where it has one and the hub itself hides apps above the person's limit. An Agents screen shows each agent such as Hermes with its token scopes and recent asks, and an owner can stop or restart every agent with the kill switch. Each screen appears only when the hub serves its route.
