The mesh is now fully mounted in the gateway (CORE-NET-8, #876). The owner turns the mesh on or off, picks its provider (Headscale) and sets the control URL with `PUT /v1/mesh/settings` or `onemind mesh settings`. The choice is stored in the settings store, written to the audit log and applied at once, with no restart. Only the owner can change it. Agents and other people get 403, and each refusal is audited. With no provider chosen, `GET /v1/mesh` says "not set up" and gives the next step. A provider that is chosen but not installed says how to install it. The box CA now starts when the mesh is turned on, and reading the mesh view no longer creates one. The join bundle's mesh block now names the provider next to the relay fields. Every older field stays, so nodes from the previous release keep joining. Turning the mesh off now stops any join that was handed a mesh key but has not passed its mesh check: the join fails, its key is expired, and a machine that already used the key is taken off the mesh, so an unchecked machine can never join that way. `GET /v1/mesh` and `onemind mesh settings --disable` now say plainly that off only stops new mesh keys: Headscale keeps running, and machines and phones that already joined stay connected.
