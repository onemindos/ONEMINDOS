The API fuzz job (api-fuzz) now passes for the agent and the owner, and the same run is clean for adult, guest, child and teen tokens too. Every finding was fixed in the gateway, and no fuzz check was turned off. Custom-app reads and the automation dry-run now list the 403 they return. The data stream's events (`record` and `end`) have a documented event schema. The If-Match headers on sync commit and work task edits now document the revision format they accept. Work task priority accepts 3.0, a numeric due date is refused, and a work cursor from another project is refused as `invalid_cursor`. The dashboard card subject documents its pattern. Bring-your-own-domain switched off now answers 409 `domains_disabled` instead of 503. A superscript or other non-ASCII digit in a cursor, Last-Event-ID, If-Match, Content-Length or TOTP code is now refused or ignored instead of causing a 500. The fuzz gateway now has a kiosk flag path, and the fuzz hook lists four refusals that only the server can judge (expiry, manifest, app-password scopes, quick-add text).
