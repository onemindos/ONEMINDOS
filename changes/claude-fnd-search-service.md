Global search, GET /v1/search. One local SQLite FTS5 index (a rebuildable cache under the gateway's cache folder, mode 0600, never backed up and never sent off the box) is fed by search providers that the built-in descriptors switch on: each switched-on built-in whose descriptor has spec.search gets the provider registered under spec.search.provider, and only the item types it declares are returned. Files and Settings are the first two providers. Files follows the Files sync index by revision, so renames and trash show up on the next query; a person sees only files their role may read (never another person's Home) and an agent only files under a folder grant the owner approved. Settings lists every built-in's Settings pages, shown to a person whose scopes allow the route the page reads. A switched-off built-in's items disappear at once. Every hit carries a deep link (onemind://app/ID/route). An agent's search is audited with the query length and hit count, never the query text. New code registers more providers with search.register_provider.
