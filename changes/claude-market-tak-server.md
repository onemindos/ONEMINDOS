TAK Server as an optional Market app (apps/tak-server), never part of the base image: TAK Server 5.7-RELEASE-14 (GPL-3.0, licence class L2, kept a separate program) with its PostgreSQL + PostGIS database as a sidecar on 127.0.0.1, both volumes on /data, a box-generated database password and keystore password in place of the upstream default, a certificate authority made on the first start and kept by the owner on the box, cold backups, and host ports 8089 and 8446 declared for the LAN only. TAK Product Center publishes no public image this app can verify, so the TAK container names an all-zero placeholder digest: the gate keeps the app blocked and the gateway refuses to install it until a later PR builds the image from source with the recipe in apps/tak-server/build/ and pins it. It pairs with OneMind's native CoT bridge. On every start, the app parses CoreConfig XML and refuses non-TLS network inputs or connectors or a configuration it cannot check. The database password is written once, and a restart test verifies that the original password is retained. The Market entry requires 40 GB of free disk. The PostGIS sidecar needs a repin before it can pass the app gate.
