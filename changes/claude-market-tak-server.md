TAK Server as an optional Market app (apps/tak-server), never part of the base image: TAK Server 5.7-RELEASE-14 (GPL-3.0, licence class L2, kept a separate program) with its PostgreSQL + PostGIS database as a sidecar on 127.0.0.1, both volumes on /data, a box-generated database password and keystore password in place of the upstream default, a certificate authority made on the first start and kept by the owner on the box, cold backups, and host ports 8089 and 8446 declared for the LAN only. TAK Product Center publishes no public image this app can verify, so the TAK container names an all-zero placeholder digest: the gate keeps the app blocked and the gateway refuses to install it until a later PR builds the image from source with the recipe in apps/tak-server/build/ and pins it. It pairs with OneMind's native CoT bridge. Review follow-ups: the start script refuses a CoreConfig with an active quic, tcp, udp or stcp input or tls="false"; the database password is written once (rotation is documented as unsupported); requires.storageFreeGb 40; the README records that the PostGIS sidecar will fail the gate until it is repinned.
