The onemind command line gains four groups that were missing next to the dashboard: `tokens` (list, create, rotate, revoke API tokens; a new secret is shown once), `secrets` (which of an app's secret settings are set, and requests to generate a new value or clear one, never showing or sending a value), `family` (a person's age limit, blocked tags, allowed apps and time windows, and an app's minimum age and tags) and `browsers` (open and close your own browser window, request erasing its profile; these work only with a dashboard or phone sign-in session, because the gateway refuses the API token `onemind login` saves, and the CLI says so in plain words). Reads print real data from the gateway, every command takes --json, and every change either files a request an owner approves or is a call the gateway already limits to the right person; the CLI never approves anything and explains the passkey step it cannot do. Refs the UI and backend parity report (M8 and the CLI half of the family row; the browsers row stays open for API tokens).
