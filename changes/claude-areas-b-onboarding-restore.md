Backups has a Restore an app from another box's backup card for the owner (new hardware): pick where the backup is, enter the old box ID and the recovery key from its kit, see the restore points, and file a request to bring one app's data back. It is never approved there and the key is kept in memory only. `onemind box-restore candidates` and `onemind box-restore app` do the same, reading the key from standard input.
