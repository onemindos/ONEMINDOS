Home and the window shell, polished (Refs #440, works with any colour direction; no token value changed). Windows lose their repeated title bar: the screen name is said once, by its heading, and the back and close buttons float over the corners of a larger-cornered, slightly see-through window with a two-layer shadow that sizes to its content. Launchpad shows your apps first and larger, system screens in a smaller row, and a 52 px search field. Home keeps its bottom padding at dock height plus 24 px, greets by a real name and never by a role ("Good morning", not "Good morning, owner"), wraps the greeting on phones (hello on one line, the whole name on the next, sized with clamp(), never cut), says "1 stale and 1 offline node", and names catalog apps as the catalog does ("Install Ollama"). Every widget has its five states: loading skeleton, empty with one action, error with Retry, last-known value with its age, and live; Backups reads the gateway's /v1/backups/status and says "No backup proved yet" with a "Set up backups" action. "(proposed)" source labels and the Coming soon screen are gone, the default Home no longer shows the raw activity log (it is in the Activity window), mock screens carry a "Demo data" badge, and the desktop app now asks the gateway's real /v1/os/updates route instead of /v1/os/status, which the gateway never served. Home's second row now holds a Trust tile (nodes online, last proved backup, last signed update), a Storage tile and Backups, so the grid is balanced; the Backups and Storage windows show the same "No backup proved yet / Set up backups" and "No storage reported yet" empty states and size to their content; a loading app widget is titled by its display name; and on phones the dock fits 390 px and the Online and Demo badges share one line. Round two: Home greets by the display name GET /v1/me gives (no name when it is absent or only a role word), the desktop Home no longer scrolls the page (the widgets scroll in a region that ends above the dock, so no button hides under it, and the wallpaper stays put), Backups and Storage open in a narrow, more see-through window, and a hub that has not answered yet says "Connecting to the hub" or "Nothing has loaded yet" instead of a last-known-state age from 1970. Round three: the whole name always shows on phones (two lines, never an ellipsis), disabled buttons use a neutral disabled style instead of a faded accent, the avatar shows the greeted name's initial instead of "?", and the Trust tile spreads its rows to match Storage.
