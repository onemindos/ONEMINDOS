Browser downloads go through quarantine before Files (#693, first part). A gateway worker takes each finished file from the person's intake folder outside every space, makes it not executable, checks its name and type (programs and archives are held) and scans it with ClamAV in a separate process. A clean file moves into the person's Home Downloads folder, never over another file, and the person gets a Downloaded item in their Inbox and a Downloaded toast in the dashboard with a way to Files. Anything else stays held and the owners get a security alert in their Inbox, from the existing notification service. A held file leaves only through files.download.release, which an owner requests (the alert's fix or POST /v1/files/downloads/{id}/release) and an owner approves; releasing an infected file is a destructive-risk approval. A missing or failing scanner never counts as clean. GET and DELETE /v1/files/downloads list and discard held files. Every move is an audited event.
