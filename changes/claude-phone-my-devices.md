My devices, first slice (Refs #715): GET /v1/me/devices lists the phones, browsers and apps signed in as you, each joining the sessions, passkeys, approver keys (when #702 is in) and push registrations of one app install, with kind and last seen. The phone makes a random install id once (secure store, this device only) and sends it, with one stored name, on sign-in, passkey and push registration (new optional install_id fields), so an old and a new phone both called "Android phone" stay two devices and a renamed phone stays one; credentials without an install id (browsers, CLI, older apps) group by name; mesh and NATS report as absent until per-person credentials exist. DELETE /v1/me/devices/{id} (Lost this device) revokes all of them in one step: a person's own session only (never an API token or agent), a fresh passkey once passkeys are on, never the device in use or the box's last owner passkey, audited as auth.device.removed and idempotent (a second call revokes nothing). The phone shows the list in Settings with Lost this device behind a second tap. The dashboard screen follows in another PR.
