The desktop shell now follows the final Atlas design. The dock starts with today's OneMind logo tile, which opens the launcher, then Home, Map (linked to /map, second), Approvals, Files, Market, Backups and Machines, with Atlas's muted tiles instead of one bright colour per screen. The top strip shows how many machines are fresh, stale and offline from GET /v1/nodes, and a needs-you chip from the requests waiting in Approvals; nothing is drawn before the hub first answers. The launcher (moved out of DesktopShell.tsx into its own module) searches apps, system screens, machines and commands with a best match, and every command shows its exact onemind line with a Copy button (a Go test resolves each line against the real CLI) or the API call where the CLI has none; anything that changes the box says "asks a person" and only files a reviewed request. The Console run bar is an option in the dock (Alt R, since Alt Space is the window menu on Windows and Linux), off by default: typed text such as "restart nextcloud" goes through the same reviewed request, a request already waiting is opened instead of filed twice, and when the bar needs room the moved apps go into a More item that names them.
