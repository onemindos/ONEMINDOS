AIG-04 (#168): an agent that read third-party text (app descriptions, node names, audit notes), through MCP (tool and resource results, tasks/get) or any REST read except the box's own instance info (a POST /v1/plans preview counts as a read), is tainted for an hour. An agent's own request and alert fix are answered without plan or result text (like MCP request_action), so owner approval policies keep working; reading the plan (GET) taints. Everything it then requests, app actions and feature actions such as system controls and MCP built-in tools alike, is filed with a taint note on the approval card (shown first, high risk, naming what it read) and in the audit log, is never accepted by a standing approval, can only be approved by the owner naming the exact plan fingerprint, and may only target apps whose aiPolicy shows them to AI. Injection test: a hostile app description tells the agent to remove an app; the agent obeys and the request still waits for a person. Carries PR #480 forward onto release/next.
