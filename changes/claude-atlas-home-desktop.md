Home on the desktop is now the Atlas desktop itself (final design screens 01 and 08b), not a dashboard page. A column of tiles sits on the wallpaper at the left: the greeting with a two-sentence summary (what needs you in bold, then what is not fine), box health, then the person's tiles with Needs you first. Every machine shows how old its last heartbeat is, fresh ones too. A request that needs a hold (it moves a device, or it cannot be undone) is never approved with one tap on Home: it says which, shows Review and Deny, and is approved in Approvals; an install that needs values the owner types also goes to Approvals. Windows now open over the wallpaper to the right of the tile column, and Home stays painted behind them; a click on the bare wallpaper brings the desktop back with the windows still where they were. Edit mode edits Home and the dock together: an edit bar with Reset to default and Done, and a tray on the right that adds tiles back (removed tiles return to it) and puts installed apps in or out of the dock. The search field and the app grid leave the desktop Home because the menu bar, the dock and the launcher carry them; the Console layout keeps the launcher page. All values come from the gateway (nodes, actions, status, backups, storage, recent visits); there is no sample data.
