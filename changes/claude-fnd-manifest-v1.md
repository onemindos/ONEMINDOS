Manifest v1: every remaining app manifest block lands in one schema change. New spec blocks runtime, placement, data, services, search, share, notifications, mapLayers, jobs, roles, continue, needs and the terms record (spec.terms), and new extension blocks bridge, connector, videoSource and nats; search, share, notifications, mapLayers and data take the built-in descriptor's shapes, so a descriptor block still validates against the App block. The gateway's Catalog.validate and the Go validator behind onemind plugin validate stay the one validator and share golden cases (sdk/testdata/manifest-v1): the terms record is mandatory for outside data, personData is always false, hosts are plain hostnames listed in egress, emits stay inside the app's own source and layers, schedules respect the hub and provider floors, non-commercial, personal-use and person-scoped terms cannot redistribute, runtime module outside the signed list, effect actuate, unknown blocks, undeclared tools and any field holding a credential are refused (errors name the field, never the value). onemind plugin validate --previous now sets widens_grants when a new version loosens hosts, keys, terms, NATS subjects, data classes, services, jobs or recording. The bridge and connector rules are in sdk/contracts/connectors.md.
