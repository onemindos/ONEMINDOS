Map v0 on the desktop (Atlas design, dock slot 2): a new Map screen at /map, second in the dock, shows the box, its nodes, the machines on them and every asset with a live value on one plan of the owner's own place. It reads only the gateway through the generated client: places from GET /v1/sites, the live asset feed from GET /v1/events?types=asset.*, nodes and machines from the existing polls, and the offline map packs from GET /v1/map/packs (named under Layers; the base map stays off). An asset is drawn on the plan only when it reports a pose in the place's frame or a WGS-84 position the place's surveyed points can fix; everything else, the box and machines included, waits on a "not on the plan yet" shelf. Every label prints its age and its state (fresh, stale, offline) with a shape as well as a colour; layers switch per asset class, state chips filter, a List view gives the keyboard and screen-reader path, and the asset card says what each value is and how old it is. With nothing reported and no place drawn it shows an empty state, never sample assets. Read only: the Map never moves anything. No map library is added; twin view, farm and operations scenes, Stop and drawing a place are follow-ups.
