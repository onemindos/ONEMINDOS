One NATS subject tree (Refs #600): sdk/schema/onemind.subjects.json registers the grammar onemind.<kind>.<scope>.<id>.<field> with eleven kinds (node, audit, event, alert, asset, intel, metric, plugin, layer, notification, request), each with its publishers, stream, retention and envelope schema (new onemind.datapoint/v1 with value, unit, time, quality, source, licence, sequence and a WGS-84 position that refuses 0,0, and onemind.event/v1). The gateway checks subjects against it (GET /v1/subjects and GET /v1/subjects/check answer with a reason), make lint fails on any subject in code that is not registered, and Go embeds the same file. Contract 12.9 is reconciled and carries the mapping table from the plugin SDK and cluster grammars; app spec.streams now land under onemind.plugin.<app_id>. and onemind.app is a reserved, refused kind, so no plugin can name a core subject. Ids ride the tree as contract 12.1 issues them (job_01HX..., usr_01HX..., case kept), job kinds keep their dots (job.backup.run, job.system.restart_unit), an agent principal agent:<name> maps to onemind.request.agent.<name>.<type> with one token per dot-separated part, and the datapoint field holding the NATS subject is nats_subject so subject keeps its event-envelope meaning.
