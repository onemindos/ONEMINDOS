# When Atlas shows the logo during loading

At startup there may be no session, screen layout or trustworthy reading yet. The OneMind mark identifies the system in that brief interval. Scale the existing mark uniformly and pair it with a status label when startup progress is known.

Once a window knows what it will show, reserve space for that content. A list of files can show rows while names arrive. During a refresh, keep the previous list visible with its age until the gateway replies. Both patterns preserve the user's place and communicate more than a repeated logo. An action in progress belongs beside the button that started it.

This rule concerns loading. The sign-in screen and product identity still use the mark in their usual roles. [Atlas design tokens](../../DESIGN.md)
