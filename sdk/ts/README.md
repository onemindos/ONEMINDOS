# @onemind/sdk (TypeScript)

The TypeScript client for the OneMind gateway API: browser, Node 20+ and React Native (pass `transport` to `events.subscribe` there). Types are generated by openapi-typescript 7.13.0 (MIT) into `src/gen/schema.ts`; the transport is hand-written and has no runtime dependencies.

```ts
import { OneMind, PermissionDeniedError } from "@onemind/sdk";

const om = new OneMind({ baseUrl: "https://hub.local:8443", token });
const nodes = await om.nodes.list();
const a = await om.actions.request({ type: "app.install", appId: "ntfy" });
await om.events.subscribe({ types: ["action.*"], signal }, (e) => console.log(e.type, e.subject));
```

The token goes only in the `Authorization` header (the event stream uses streaming `fetch`, not `EventSource`, for that reason). Regenerate with `make -C sdk gen`; test with `make -C sdk test-ts`.
